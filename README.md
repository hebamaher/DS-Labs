# Data Structures Labs – C++ Implementation

This repository contains C++ implementations of fundamental data structures as part of laboratory work.  
Each lab focuses on building the data structure **from scratch**, without using STL containers, to fully understand internal behavior and memory management.

---

## Implemented Labs

### 1. Linked List Lab
**Data Structure:**  
- Singly Linked List  
- Doubly Linked List  

**Operations Implemented:**
- Insert (Head, Tail, Before, After)
- Delete (by value, by position)
- Count nodes
- Get data by index
- Reverse list (in-place)
- Create a new reversed list
- Intersection of two sorted lists
- Remove every K-th element

### 2️. Stack & Queue Lab
**Data Structures:**
- Stack (Linked List-based)
- Queue (Shift Queue & Circular Queue)

**Operations Implemented:**
- Stack: push, pop, peek, isEmpty, isFull
- Queue: enqueue, dequeue, front, isEmpty, isFull
  
---

### 3. Sorting Algorithms Lab
- Bubble Sort
- Selection Sort
- Merge Sort
- Quick Sort

**Operations Implemented:**
- Sorting a matrix
- Sorting elements by frequency
- Binary Search (Iterative, Recursive)
  
### 4. Binary Search Tree (BST) Lab
**Data Structure:**  
- Binary Search Tree

**Operations Implemented:**
- Insert node
- Search for a value
- Delete node
- In-order traversal
- Pre-order traversal
- Post-order traversal

**Concepts Covered:**
- Recursive algorithms
- Tree traversal
- BST properties
- Node replacement during deletion

---

### 5. Graph Lab
**Graph Representation:**
- Adjacency Matrix

**Operations Implemented:**
- Graph construction
- Print adjacency matrix
- Breadth First Search (BFS)
- Depth First Search (DFS)

**Concepts Covered:**
- Graph traversal
- Queue usage in BFS
- Recursion in DFS
- Visited tracking
